# Credo v0.13.1

Credo v0.13.1 modernizes the framework's internals for Go 1.27 and expands
the copyable reference documentation. There are no intended public API or
wire-format changes. Credo remains Beta and pre-1.0.

The root module and Bun SQL wrapper are published in lockstep:

| Module | Version |
| --- | --- |
| `github.com/credo-go/credo` | `v0.13.1` |
| `github.com/credo-go/credo/store/sqldb` | `v0.13.1` |

## Requirements and installation

This release requires Go 1.27.

```sh
go get github.com/credo-go/credo@v0.13.1
go get github.com/credo-go/credo/store/sqldb@v0.13.1
```

Applications that do not use SQL only need the root module.

## Go 1.27 modernization

Credo now consistently uses the modern standard-library and language forms
available at its Go 1.27 baseline, including `slices.Clone`, streaming split
iterators, integer ranges, `clear`, `strings.CutLast`, `url.URL.Clone`, typed
slice sorting, `errors.AsType`, and the built-in `min` and `max` functions.
Redundant loop-variable captures have also been removed where Go 1.22's
per-iteration variables make them unnecessary.

UUID validation now delegates parsing to Go 1.27's standard `uuid` package.
Credo keeps its established validation contract: canonical hyphenated UUIDs
and 32-digit plain UUIDs are accepted, while braced and `urn:uuid:` forms stay
rejected.

These are internal maintenance changes. Handler behavior, JSON profiles,
error envelopes, routing contracts, and exported APIs are unchanged.

## Reference documentation

The copyable YAML and JSON configuration references and the English/Turkish
locale catalogs now cover more of the framework's current configuration and
message surface. Their conformance tests continue to verify that the examples
stay parseable and aligned.
